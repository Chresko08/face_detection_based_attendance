System Architecture & Pipeline

How the end-to-end computer vision workflow operates from raw video capture to CSV ledger logging.

Phase 1

Image Acquisition

The camera captures webcam frames at 1280x720. detectMultiScale applies the Haar Cascade frontal face model, locates face bounding boxes, converts to grayscale, and stores 200 cropped .jpg samples per student.

Target: dataset/Name.ID.sampleNum.jpg
Phase 2

Feature Training (LBPH)

cv2.face.LBPHFaceRecognizer extracts 3x3 local binary patterns for each pixel, generates concatenated spatial histograms, and fits against student roll numbers. Serialized to an exportable YAML model.

Model: model/trained_model2.yml
Phase 3

Real-Time Logging

The recognizer compares live video faces with trained histograms. If Chi-Square distance confidence is below 100, identity is recognized, duplicate attendance for the day is blocked, and an entry is committed to CSV.

Output: Attendance.csv

Algorithms In Action

Deep technical breakdown of Viola-Jones Haar Cascades and Local Binary Patterns Histograms.

01

Viola-Jones Haar Cascade Classifiers

haarcascade_frontalface_default.xml

Haar Cascades detect faces by evaluating rectangular Haar-like features (edge, line, and four-rectangle features) across an image. Using Integral Images, box sums are calculated in constant time $O(1)$ regardless of size.

  • scaleFactor (1.2 - 1.3): Compensates for faces positioned closer or further from the webcam lens by scaling the detection window.
  • minNeighbors (5): Enforces that a candidate region must have at least 5 overlapping neighbor detections to eliminate false positives.
  • AdaBoost Selection: Filters thousands of features down to the most critical discriminating facial landmarks (eyes, nose bridge, mouth).
02

Local Binary Patterns Histograms (LBPH)

cv2.face.LBPHFaceRecognizer

LBPH labels image pixels by thresholding each 3x3 neighborhood against the center pixel value, resulting in an 8-bit binary number. This produces an illumination-invariant texture representation that retains accuracy even under varying ambient lighting.

  • Spatial Grid Division: Divides face images into $m \times n$ sub-regions to preserve regional spatial layout (e.g. eyes vs jawline).
  • Histogram Concatenation: Generates histograms for each cell and chains them into a unified feature vector.
  • Chi-Square Distance Confidence: Compares probe histograms with dataset histograms. A lower distance indicates higher facial similarity ($confidence < 100$).

Quickstart & Local Installation

Run the native desktop application in your local Python environment in four simple steps.

STEP 1: Clone Repository 
git clone https://github.com/Chresko08/face_detection_based_attendance.git
cd face_detection_based_attendance
STEP 2: Set Up Virtual Environment (Optional but Recommended) 
python3 -m venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate
STEP 3: Install Required Dependencies 
pip install -r FinalProject/requirements.txt
# Or manually install core modules:
pip install opencv-python opencv-contrib-python pillow numpy pandas
STEP 4: Run the Application 
cd FinalProject
python3 App_Train_model.py
